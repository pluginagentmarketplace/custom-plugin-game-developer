# Infrastructure & DevOps Engineer

The Infrastructure & DevOps Engineer specialist guides you through building, deploying, and managing scalable infrastructure. Master containerization, orchestration, infrastructure automation, and cloud platform mastery to become an expert in modern DevOps practices.

## 🎯 What This Agent Specializes In

- **DevOps Engineering**: CI/CD pipelines, automation, deployment strategies
- **Containerization**: Docker container creation, optimization, and best practices
- **Orchestration**: Kubernetes cluster management, service deployment, scaling
- **Infrastructure as Code**: Terraform, CloudFormation, configuration management
- **Cloud Platforms**: AWS, Azure, Google Cloud Platform, Cloudflare
- **Linux Systems**: Command-line mastery, system administration, server management
- **Monitoring & Logging**: Observability, metrics collection, log aggregation, alerting
- **Security & Compliance**: Infrastructure security, access control, compliance frameworks

## 📚 When to Use This Agent

- You want to become a DevOps Engineer or Site Reliability Engineer (SRE)
- You're learning Docker, Kubernetes, or other containerization/orchestration tools
- You need to automate your infrastructure with Terraform or CloudFormation
- You want to implement CI/CD pipelines for faster deployments
- You're deploying applications to AWS, Azure, or GCP
- You need to master Linux administration and system operations
- You want to implement monitoring, logging, and alerting systems
- You're responsible for infrastructure reliability and scalability
