# /browse-role - Browse All 66 Development Roles

Explore all available development roles and career paths from the developer-roadmap repository.

## Usage

```
/browse-role
/browse-role [category]
/browse-role [search-term]
```

## Categories

- **web**: Web development roles (12 roles)
- **devops**: Infrastructure and DevOps (8 roles)
- **data-ai**: Data Science and AI (10 roles)
- **architecture**: System Design and Architecture (6 roles)
- **mobile-game**: Mobile and Game Development (12 roles)
- **security**: Security and Quality (8 roles)
- **professional**: Professional Development (10 roles)

## What It Does

Browse and explore:

1. **All 66 Roles** - Complete list of available development roles
2. **Role Descriptions** - Understand what each role entails
3. **Responsibilities** - Key duties and daily activities
4. **Required Skills** - Technical and soft skills needed
5. **Career Progression** - Typical career advancement paths
6. **Salary Ranges** - General compensation information
7. **Job Market** - Demand and growth trends
8. **Start Learning** - Quick link to `/learn` for any role

## Example Usage

```
/browse-role
# Shows all 66 roles organized by category

/browse-role web
# Shows all 12 web development roles

/browse-role data-ai
# Shows all 10 data science and AI roles

/browse-role machine learning
# Shows roles matching "machine learning"

/browse-role DevOps Engineer
# Shows specific role details
```

## Benefits

- **Career Exploration** - Discover roles you didn't know existed
- **Market Research** - Understand job market and demand
- **Skill Gaps** - Identify what you need to learn
- **Networking** - Find community and professionals in different roles
- **Comparison** - Compare different roles side by side
- **Decision Making** - Make informed career choices

## Role Information Includes

For each role you can learn:
- **Overview**: What the role is about
- **Day-to-Day**: Typical daily activities
- **Skills Required**: Technical, soft, and business skills
- **Learning Path**: How to prepare for the role
- **Certifications**: Relevant certifications
- **Tools & Tech Stack**: Technologies commonly used
- **Related Roles**: Similar or adjacent roles
- **Resources**: Curated learning materials
- **Communities**: Where to find professionals

## Linked to Learning

Once you find a role you're interested in:

1. Use `/learn` to start the learning path
2. Use `/assess` to check your knowledge
3. Use `/projects` to find hands-on projects
4. Join communities and start building!

---

**Tip**: Found an interesting role? Use `/learn [role-name]` to start learning!
