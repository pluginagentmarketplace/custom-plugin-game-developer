# Game Engines & Frameworks

## Quick Start

Choose your engine based on your goals:

- **Unity**: Most popular, easy to learn, mobile-friendly (C#)
- **Unreal Engine**: High-end graphics, AAA standard (C++)
- **Godot**: Lightweight, open-source, beginner-friendly (GDScript)

## Unity Engine (Most Used)

**Language**: C#
**Best for**: 2D/3D games, mobile, indie

- Scene and GameObject architecture
- Components and prefabs
- Physics engine (2D and 3D)
- Animation system
- UI Canvas system
- Asset Store ecosystem
- Cross-platform deployment
- Asset management

## Unreal Engine

**Language**: C++ / Blueprints
**Best for**: AAA, high-end graphics, large teams

- Unreal Editor
- C++ programming with Blueprints
- Actor and Component system
- Advanced physics (Havok)
- Material system (advanced shaders)
- Animation system (Sequencer)
- Niagara particle system
- Networking and replication

## Godot Engine

**Language**: GDScript
**Best for**: 2D games, learning, indie

- Scene system
- GDScript language
- Signals for communication
- 2D physics engine
- Animation nodes
- Shader language
- Export to multiple platforms
- Lightweight and fast

## Key Concepts

- **Scenes**: Reusable game components
- **Prefabs/Nodes**: Instances of scenes
- **Physics**: Colliders, rigidbodies, forces
- **Animation**: Timeline-based or code-based
- **UI System**: Menus, HUDs, dialogs
- **Particle Systems**: Effects, explosions, magic
- **Audio Integration**: Sound, music, spatial audio
- **Networking**: Multiplayer support

## Learning Paths

**Beginner** (2-3 months):
- Engine fundamentals
- Creating first game (simple 2D or 3D)
- Physics and colliders
- Input handling

**Intermediate** (3-4 months):
- Advanced systems
- Optimization techniques
- Asset workflow
- Publishing to platform

**Advanced** (3-6 months):
- Custom systems development
- Advanced physics
- Shader creation
- Engine extension
