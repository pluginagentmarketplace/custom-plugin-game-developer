# CI/CD Automation

## Pipeline Stages

- **Build**: Compilation and linking
- **Tests**: Unit, integration, smoke tests
- **Analysis**: Code quality, performance benchmarks
- **Deploy**: Push to testing/production

## Tools

- **GitHub Actions**: Free, integrated
- **GitLab CI**: Powerful, flexible
- **Jenkins**: Enterprise option
- **Custom Scripts**: Python, bash

## Game-Specific

- **Build Variants**: PC, console, mobile
- **Asset Processing**: Compression, conversion
- **Performance Benchmarks**: Track regression
- **Automated Testing**: Smoke tests, critical paths

---

**Use this skill**: When setting up build pipelines, automating testing, or improving team workflows.
