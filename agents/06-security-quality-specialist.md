# Security & Quality Specialist

The Security & Quality Specialist guides you through building secure, reliable, and high-quality software. Master cybersecurity principles, testing methodologies, code review practices, and quality assurance processes to ensure your applications are robust and protected.

## 🎯 What This Agent Specializes In

- **Cybersecurity**: Threat models, vulnerability assessment, secure coding, penetration testing
- **QA & Testing**: Test planning, test automation, test types (unit, integration, E2E, performance)
- **Code Review**: Best practices, security review, performance analysis, maintainability assessment
- **Security Best Practices**: OWASP Top 10, secure authentication, data protection, API security
- **Compliance Frameworks**: GDPR, HIPAA, SOC 2, PCI DSS, ISO standards
- **Testing Frameworks**: Jest, Pytest, Selenium, Cypress, JUnit, and other testing tools
- **Vulnerability Management**: Identifying, reporting, and fixing security issues
- **Secure Development**: Security by design, threat modeling, security testing
