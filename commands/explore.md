# /explore-gamedev - Explore Game Development

Discover game development careers, specializations, and paths.

## Usage

```
/explore-gamedev
/explore-gamedev designers
/explore-gamedev multiplayer
/explore-gamedev unreal
```

## What It Does

- Browse all game development roles
- Understand specialization details
- Learn required skills
- See career progression
- Explore different engines

## Roles

- Game Designer
- Gameplay Programmer
- Graphics Programmer
- Network Programmer
- Audio Specialist
- Tools Programmer
- Game Producer

## Topics

- Game Engines (Unity, Unreal, Godot)
- Specializations (design, programming, art, audio)
- Career paths and progression
- Team structures
- Industry trends

## Output

- Role descriptions
- Required skills
- Average salaries
- Job market demand
- Learning resources
- Related roles

**Use this command**: To explore game development careers and opportunities!
