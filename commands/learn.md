# /learn - Start Learning Path

Discover and start a learning path for any of the 66 development roles available in this plugin.

## Usage

```
/learn
```

## What It Does

This command helps you:

1. **Discover Your Role** - Browse all 66 available development roles
2. **Assess Current Level** - Understand if you're a beginner, intermediate, or advanced
3. **Get Personalized Path** - Receive a customized learning roadmap
4. **Find Resources** - Access curated learning materials for your chosen role
5. **Track Progress** - Monitor your advancement through the learning path

## Learning Path Includes

- **Roadmap**: Step-by-step progression from beginner to expert
- **Skills**: Specific skills needed for the role
- **Timeline**: Expected learning time (typically 6-18 months for mastery)
- **Resources**: Books, courses, tutorials, and communities
- **Projects**: Hands-on projects to practice and build portfolio
- **Mentorship**: Guidance on finding mentors and networking

## Getting Started

Use this command to:

1. Explore available roles
2. Find a role that matches your interests
3. Understand the learning path
4. Get access to curated resources
5. Begin your learning journey

**Tip**: Use `/assess` after some learning to evaluate your knowledge!
