# Shader Techniques

## Core Shaders

- **Vertex**: Geometry transformation
- **Fragment**: Per-pixel coloring
- **Custom**: Domain-specific effects

## Effects

- **Normal Mapping**: Surface detail without geometry
- **Parallax Mapping**: Depth illusion
- **Procedural Textures**: Generated patterns
- **Distortion**: Screen-space effects

## Optimization

- Shader complexity reduction
- Texture atlasing
- LOD systems
- Mobile-specific optimizations
