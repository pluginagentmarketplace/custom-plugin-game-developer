# /learn-gamedev - Start Learning Game Development

Begin your game development journey with personalized learning paths.

## Usage

```
/learn-gamedev
/learn-gamedev [specialization]
/learn-gamedev unity designer
/learn-gamedev unreal programmer
```

## What It Does

- Choose game development specialization
- Get personalized learning roadmap
- Find recommended resources
- Track progress through learning
- Get community support

## Specializations

- **Game Designer** - Mechanics, levels, UX/UI
- **Game Programmer** - Engine systems, gameplay code
- **Graphics Programmer** - Shaders, VFX, optimization
- **Audio Specialist** - Sound design, music, implementation
- **Network Programmer** - Multiplayer, servers, netcode
- **Tools Programmer** - Pipelines, automation, extensions
- **Game Producer** - Publishing, marketing, live ops

## Engines

- **Unity** (C#, most popular)
- **Unreal Engine** (C++, AAA standard)
- **Godot** (GDScript, open source)

## Output

- Customized learning path (8-18 months)
- Step-by-step progression
- Project suggestions
- Resource recommendations
- Timeline and milestones
