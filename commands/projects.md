# /gamedev-projects - Game Development Projects

Discover hands-on game development projects from beginner to professional level.

## Usage

```
/gamedev-projects
/gamedev-projects beginner
/gamedev-projects unity advanced
/gamedev-projects multiplayer
/gamedev-projects graphics
```

## Difficulty Levels

- **Beginner** (1-2 weeks)
  - Simple 2D platformer
  - Pong or breakout clone
  - Game jam-style project

- **Intermediate** (2-4 weeks)
  - 3D first-person game
  - Top-down RPG
  - Puzzle game

- **Advanced** (4-8 weeks)
  - Multiplayer game
  - Complex systems
  - Polished indie game

- **Professional** (8+ weeks)
  - Shipped commercial game
  - Large systems
  - Cross-platform support

## Project Types

- Single-player games
- Multiplayer games
- 2D games
- 3D games
- Game jam entries
- Portfolio games

## Features

- Complete project descriptions
- Step-by-step guides
- Code examples
- Asset resources
- Testing criteria
- Publishing checklist

## Output

- Project list by difficulty
- Project details and scope
- Resource links
- Learning outcomes
- Time estimates
