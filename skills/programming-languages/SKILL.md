# Game Programming Languages

## C# (Unity)

**Easiest to learn**, **most used for game dev**

- Object-oriented, managed memory
- Syntax similar to Java
- LINQ for data queries
- Coroutines for game logic
- Events and delegates
- Garbage collection (performance consideration)

**Learning Path**: 2-3 weeks basics, 2-3 months mastery

## C++ (Unreal Engine)

**Most powerful**, **steepest learning curve**

- Manual memory management
- Templates and STL
- High performance
- Complex but powerful
- Meta-programming capabilities
- Reflection system in Unreal

**Learning Path**: 4-6 weeks basics, 4-6 months proficiency

## GDScript (Godot)

**Python-like**, **easiest syntax**

- Dynamic typing
- Simple syntax
- Perfect for beginners
- Signals for messaging
- First-class functions
- Growing ecosystem

**Learning Path**: 1-2 weeks basics, 4-8 weeks proficiency

## Key Programming Concepts

- **Object-Oriented**: Classes, inheritance, polymorphism
- **Design Patterns**: Singleton, observer, state machine
- **Memory Management**: Allocations, pooling, garbage collection
- **Coroutines**: Async operations, delays, animations
- **Callbacks**: Event systems, delegates
- **Profiling**: Memory, CPU, GPU performance analysis
